# Image Stitching Tool

A Python tool for cropping overlapping image fragments and stitching them back together.

## Installation

1. To install the required packages, run:


Windows:
```bash
pip install -r requirements.txt
```

Linux:
```bash
pip3 install -r requirements.txt
```




## Usage

1. Running process_and_stitch.py:

```bash
python3 process_and_stitch.py <path_to_image>
```
